# Clinical-Trial-Data-Analysis-R

## Project Overview
This project focuses on analyzing clinical trial patient data using R programming. It includes patient demographics, adverse events, age distribution, weight summaries, and basic statistical analysis.

## Tools Used
- R Programming
- RStudio
- CSV datasets
- Data Visualization

## Project Activities
- Created and imported clinical trial datasets.
- Performed data cleaning and preprocessing.
- Analyzed patient demographic information.
- Summarized adverse events.
- Calculated age and weight summaries.
- Created data visualization charts.
- Exported summary reports as CSV files.

## Files Included
- 01_create_dataset.R – Main R script
- Patient_Data.csv – Patient dataset
- Adverse_Events.csv – Adverse events dataset
- AE_Summary.csv – Adverse events summary
- Age_Summary.csv – Age summary
- Weight_Summary.csv – Weight summary
- Patient_Distribution.png – Patient distribution graph
